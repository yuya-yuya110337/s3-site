AWS S3 Site

AWS S3 を利用して静的 Web サイトを公開した学習プロジェクトです。 バケットの作成、パブリックアクセス設定、静的ウェブサイトホスティングの有効化、バケットポリシーの設定など、S3 を用いた Web 公開の基本的な流れを一通り経験しました。 HTML/CSS で作成したページをアップロードし、S3 のエンドポイントから実際にアクセスできる状態まで構築しています。

使用技術など

AWS S3, 静的ウェブサイトホスティング, バケットポリシー, HTML/CSS, Git / GitHub

EC2 Nginx Practice

AWS EC2（Amazon Linux 2023）上に Nginx を構築し、静的 Web サーバーとして公開した学習プロジェクトです。 Nginx のインストール、設定ファイルの編集、公開ディレクトリの構成、systemctl によるサービス管理など、Web サーバーの基本的な仕組みを理解しながら構築しました。 また、セキュリティグループの設定やパブリック IP を用いた動作確認など、AWS 上での公開手順も一通り経験しています。

使用技術など

AWS EC2, Nginx, Amazon Linux 2023, HTML/CSS, Git / GitHub,systemctl（サービス管理）, セキュリティグループ（AWS）
